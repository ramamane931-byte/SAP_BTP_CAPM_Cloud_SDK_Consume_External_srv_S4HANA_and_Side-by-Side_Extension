## Push this application main folder to the GitHub repository:

#### Use commands:

1. git init

2. git add .

3. git commit -m "first commit"

4. git branch -M main

5. git remote add origin https://github.com/ramamane931-byte/SAP_BTP_CAPM_Cloud_SDK_Consume_External_srv_S4HANA_and_Side-by-Side_Extension.git

6. git push -u origin main

##
